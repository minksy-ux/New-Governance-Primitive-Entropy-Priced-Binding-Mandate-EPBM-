# Verifier Admission and Removal Constitution

## Purpose
Define transparent, deterministic policy for verifier onboarding/removal.

## Admission Criteria
1. Operational security controls documented.
2. Public accountability identity and contact path.
3. Independent technical review completed.
4. Conflicts-of-interest disclosure published.

## Removal Triggers
1. Key compromise.
2. Repeated policy violation.
3. Malicious attestation behavior.
4. Governance vote for removal.

## Process
1. Proposal with evidence bundle.
2. Challenge window.
3. Final decision and queued onchain execution.
4. Post-action disclosure.
