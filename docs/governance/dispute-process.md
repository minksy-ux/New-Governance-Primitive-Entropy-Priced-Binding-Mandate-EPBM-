# Governance Dispute Process

## Scope
Disputes over fork legitimacy, verifier actions, and governance procedure.

## Stages
1. Intake and triage.
2. Evidence publication.
3. Open challenge period.
4. Decision with explicit criteria.
5. Appeal window (if applicable).

## Decision Criteria
- Onchain objective state
- Policy conformance
- Security and liveness impact
- Ecosystem coordination impact
