# Public Drill Program

## Objective
Move from internal tabletop confidence to public, externally witnessed operational confidence.

## Cadence
1. Minimum quarterly drill cycle.
2. At least one disputed-fork scenario every two cycles.
3. At least one verifier-compromise scenario every cycle.

## External Participation Requirement
Each public drill must include:
- at least two external participants
- one independent observer with no signer authority
- witness attestation using template in runs/WITNESS_ATTESTATION_TEMPLATE.md

## Evidence Pack For Each Run
1. Drill run file with timeline and decisions.
2. Command outputs for checks and tests.
3. Witness attestations.
4. Follow-up actions with owner and due date.

## Exit Criteria For Production Confidence
1. Three consecutive drill cycles completed with external participants.
2. All critical corrective actions from prior cycle closed.
3. Public post-drill summaries published within SLA.
